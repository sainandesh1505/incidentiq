# IncidentIQ — 3-minute demo

**0:00–0:25 — Problem:** Production incidents repeat, but useful fixes can be buried in old incident reports.

**0:25–0:55 — Memory:** Click Seed historical incidents. Explain that Hindsight retains symptoms, root causes, resolutions, runbooks and post-mortems.

**0:55–1:40 — Recall:** Use the 503 Payment API incident and click Find similar incidents. Show the recalled historical incident.

**1:40–2:30 — Reflect:** Click Generate response plan. Explain that Reflect reasons over remembered experience and produces an investigation and response plan.

**2:30–3:00 — Takeaway:** IncidentIQ makes incident response experience-aware while keeping humans in control of production changes.
